<B>Scenario</B>
To avoid spreading germs, many places now prefer contactless systems like automatic hand sanitizers and touchless doorbells.

<B>Problem Statement</B>
Create a touch-free doorbell using a single IR sensor that rings a buzzer when someone waves their hand near it.

<B>Components:</B>
    * Arduino Uno
    * IR Proximity Sensor
    * Buzzer
    * LED (optional for visual alert)
    * Jumper Wires, Breadboard

<B>How It Works:</B>
    * The IR sensor detects an object (hand) within a short distance (e.g., 5–10 cm).
    * When a hand is waved near the sensor, the Arduino activates a buzzer and optionally lights up an LED to signal that someone is at the door.
    * The system resets after a few seconds and waits for the next hand wave.
